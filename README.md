# ClearAllergy

外食時にアレルゲン情報を確認できるページを、店舗が登録・更新できる形で提供するWebアプリ。

## Demo

- （デモURLがあれば）
- （GIF/スクショをここに）

## Features

### For users

- 店舗一覧の閲覧
- 店舗詳細（メニュー/アレルゲン）の閲覧

### For restaurants (admin)

- ログイン
- 店舗情報編集
- メニュー CRUD
- アレルゲン登録（日本向け28品目）
