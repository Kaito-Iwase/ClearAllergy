# 管理画面の公開条件と入力ルール

## 目的

ClearAllergy の管理画面で、保存できる条件と公開できる条件を分けて固定するための文書です。

この文書は 2026-04-21 時点の実装確認に基づきます。確認できない内容は「未確定」として扱い、推測で既存仕様にしません。

## 現在の確認事実

| 項目 | 確認できた事実 | 主な確認箇所 |
| --- | --- | --- |
| メニュー公開判定 | `getMenuPublishValidationErrors` がサーバー側の公開可否を判定している | `lib/allergens.ts` |
| 新規メニュー公開 | `POST /api/admin/menus` で `isPublished: true` の場合のみ公開条件を検証する | `app/api/admin/menus/route.ts` |
| メニュー更新公開 | `PUT /api/admin/menus/[menuId]` で保存後も `isPublished: true` になる場合は毎回公開条件を検証する | `app/api/admin/menus/[menuId]/route.ts` |
| メニュー名 | 公開条件に使われる。空白だけの場合は公開不可 | `lib/allergens.ts` |
| アレルゲン28品目 | 公開条件に使われる。1件でも `UNKNOWN` があると公開不可 | `lib/allergens.ts` |
| 原材料名 | 画面文言では「未入力でも保存・公開できますが、できるだけ入力をおすすめします。」。公開条件には使われていない | `NewMenuForm.tsx`, `MenuEditClient.tsx`, `lib/allergens.ts` |
| 注意書き | 画面文言では「未入力でも保存・公開できますが、できるだけ入力をおすすめします。」。公開条件には使われていない | `NewMenuForm.tsx`, `MenuEditClient.tsx`, `lib/allergens.ts` |
| 価格 | 空欄保存可。入力時は 0 以上の整数、Prisma Int 上限以下 | `lib/validators/admin-input.ts` |
| 店舗名 | 店舗情報保存では必須。空白だけは保存不可 | `components/admin/shop/ShopEditClient.tsx`, `app/api/admin/shop/route.ts` |
| 店舗情報 | 説明、住所、営業時間、定休日、電話番号、備考、平均予算、画像は公開ページに表示され得るが、店舗公開可否の独立した判定関数は未確認 | `app/api/admin/shop/route.ts`, `app/(public)/shops/[shopId]/page.tsx` |
| アレルゲン欠損 | マスタ基準で欠けているリンクは `UNKNOWN` として扱う | `createStatusBySlug`, `buildAllergenRows` |

## 未確定事項

| 未確定事項 | 理由 |
| --- | --- |
| 「店舗が公開状態になる条件」の正式仕様 | `Shop.isActive` は公開ルートで使われるが、管理画面での公開切替フォームや専用公開条件文書は未確認 |
| 原材料名と注意書きを将来必須にするか | 現行実装では公開必須ではなく、画面文言も推奨扱い |
| `UNKNOWN` を公開画面で今後も表示し続けるか | 現行表示は維持されているが、公開不可条件により通常の新規公開データでは出ない想定 |
| `FREE` の法的・業務的な表現 | 現行 UI は「含まない」だが、免責や表現の最終判断は未確定 |

## 項目ごとの必須 / 推奨 / 任意

「公開必須」は、現行サーバー実装で `isPublished: true` にするために必要な項目です。

| 対象 | 項目 | 保存 | 公開 | 根拠 |
| --- | --- | --- | --- | --- |
| メニュー | メニュー名 | 必須に近い。新規 API は未指定時に「新しいメニュー」を補完、編集 API は空を拒否 | 必須 | `POST /api/admin/menus`, `PUT /api/admin/menus/[menuId]`, `getMenuPublishValidationErrors` |
| メニュー | アレルゲン28品目 | 保存可。未指定や欠損は `UNKNOWN` 補完 | 必須。全品目が `UNKNOWN` 以外 | `createStatusBySlug`, `getMenuPublishValidationErrors` |
| メニュー | 原材料名 | 任意 | 推奨。公開必須ではない | 画面文言と公開判定 |
| メニュー | 注意書き | 任意 | 推奨。公開必須ではない | 画面文言と公開判定 |
| メニュー | 価格 | 任意。入力時は 0 以上の整数 | 任意 | `parsePriceYen` |
| メニュー | 説明 | 任意 | 任意 | API で nullable string |
| メニュー | カテゴリ | 任意 | 任意 | API で nullable string |
| メニュー | 食品画像 | 任意。保存する場合は画像 URL 検証あり | 任意 | `validateStoredImageUrl` |
| 店舗 | 店舗名 | 必須 | 公開表示に使う | `app/api/admin/shop/route.ts` |
| 店舗 | 説明 | 任意 | 表示対象 | `app/(public)/shops*.tsx` |
| 店舗 | 平均予算 | 任意。入力時は 0 以上の整数 | 表示対象 | `parseAverageBudgetYen` |
| 店舗 | 住所 | 任意 | 表示対象 | `app/(public)/shops*.tsx` |
| 店舗 | 営業時間 | 任意 | 表示対象 | `ShopEditClient.tsx`, 公開店舗詳細 |
| 店舗 | 定休日 | 任意 | 表示対象 | `ShopEditClient.tsx`, 公開店舗詳細 |
| 店舗 | 電話番号 | 任意 | 表示対象 | `ShopEditClient.tsx`, 公開店舗詳細 |
| 店舗 | 備考 | 任意 | 表示対象 | `ShopEditClient.tsx`, 公開店舗詳細 |
| 店舗 | 店舗画像 | 任意。保存する場合は画像 URL 検証あり | 表示対象 | `validateStoredImageUrl` |

## 公開条件に使う項目 / 使わない項目

### メニューの `isPublished` 変更時に使う項目

| 項目 | 判定 |
| --- | --- |
| メニュー名 | `trim()` 後に空なら公開不可 |
| アレルゲン28品目 | 1件でも `UNKNOWN` なら公開不可 |

### メニューの `isPublished` 変更時に使わない項目

| 項目 | 現行の扱い |
| --- | --- |
| 原材料名 | 公開必須ではない。管理画面上は入力推奨 |
| 注意書き | 公開必須ではない。管理画面上は入力推奨 |
| 価格 | 公開必須ではない |
| 説明 | 公開必須ではない |
| カテゴリ | 公開必須ではない |
| 食品画像 | 公開必須ではない |

## UNKNOWN の扱い

| 状態 | 管理画面ラベル | 公開画面ラベル | 公開可否への影響 |
| --- | --- | --- | --- |
| `UNKNOWN` | 未設定 | 未設定 | 1件でもあるとメニュー公開不可 |
| `CONTAINS` | 含む | 含む | 公開可 |
| `FREE` | 含まない | 含まない | 公開可 |
| `MAY_CONTAIN` | 含む可能性があります | 含む可能性があります | 公開可 |

補足:

- DB の `MenuItemAllergen.status` の default は `UNKNOWN`。
- `createStatusBySlug` はアレルゲンマスタ全件をまず `UNKNOWN` で埋め、保存済みリンクで上書きする。
- 公開画面は `UNKNOWN` を隠さず表示する設計になっている。
- 管理メニュー一覧は `UNKNOWN` があるメニューを「未設定あり」として警告する。

## 保存条件と公開条件の違い

| 操作 | 条件 |
| --- | --- |
| 下書き保存 | メニュー名、価格形式、画像 URL、アレルゲン map の形式など、各 API の保存バリデーションを通れば保存できる |
| 公開保存 | 下書き保存条件に加えて、メニュー名が空でないこと、アレルゲン28品目がすべて `UNKNOWN` 以外であること |
| 店舗情報保存 | 店舗名が必須。平均予算は 0 以上の整数。画像 URL は許可済み形式のみ |

## 管理画面文言の統一方針

現行文言に合わせる場合の基準です。

| 状況 | 推奨文言 |
| --- | --- |
| 原材料名 | 「未入力でも保存・公開できますが、できるだけ入力をおすすめします。」 |
| 注意書き | 「未入力でも保存・公開できますが、できるだけ入力をおすすめします。」 |
| アレルゲン未設定 | 「未設定」 |
| 公開不可 | 「公開するにはアレルゲン28品目を確定してください。」 |
| 下書き状態 | 「非公開」または一覧では「下書き」。現状は画面によって併用されている |

## 今後実装で合わせるべき点

| 優先 | 提案 | 理由 |
| --- | --- | --- |
| 高 | `/` と `/api/menus/[menuId]` の `shop.isActive` 条件を公開画面と揃える | 公開店舗一覧・店舗詳細との条件差をなくす |
| 高 | 管理一覧の「公開準備」文言にメニュー名も含める | 公開条件と UI 文言を一致させる |
| 中 | `非公開` と `下書き` の用語を画面ごとに定義する | 状態名の揺れを減らす |
| 中 | 原材料名・注意書きは「推奨」で固定し、必須化する場合は別 Issue にする | 現行 API と画面文言に合わせる |
| 中 | 公開条件のテストを `getMenuPublishValidationErrors` 中心に追加する | UI 変更時に公開条件が壊れにくくなる |
