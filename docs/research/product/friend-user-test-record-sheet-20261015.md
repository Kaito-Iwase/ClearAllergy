分類候補は「根拠付きで区別できた／混同した／回答から判定不能／未評価」。不明なことを不明と説明できた回答を、隠れた真値と違うという理由で誤答にしない。初見で触れなかった点を、標準質問で初めて説明した場合も分ける。

| 誤認・留保の確認 | 記入欄 |
| --- | --- |
| UNKNOWNをFREEと読んだ / 使用情報を見落とした | 該当 / 非該当 / この条件では評価できない |
| FREEから摂取可・厨房全体・交差接触なしを推論した | 該当 / 非該当 / 評価できない |
| 別料理・別版・表示時刻を取り違えた | 該当 / 非該当 / 評価できない |
| 停止だけで使用・事故・理由を推測した | 該当 / 非該当 / 評価できない |
