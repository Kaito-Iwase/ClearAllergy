## 変更

1. QRのURLを共通の純粋関数で決定します。設定はHTTP(S)のoriginのみ許可し、公開環境で残ったlocalhost等は現在のoriginへ戻します。有効な外部設定とローカル開発は維持します。表示・リンク・コピー・QRが同じ値を使います。Vercel設定は変更していません。
2. メニュー編集の保存前に、品目入力・食品確認・公開予定を分けて表示します。食品変更なしの価格編集と、食品変更時の再確認を区別します。確認日時の未来許容は既存サーバーと同じ5分境界を共有します。保存後は検証済み応答の公開フラグと確認対応版で確定結果を表示し、キャッシュ反映待ちを保存失敗と混同しません。
3. 店舗フォームを先頭に置き、画像の構図・公開プレビュー・QR・入力のヒントを初期状態で閉じたdetailsにします。入力・画像の保存経路は維持します。管理Shellを文書全体のスクロールにし、タブレットを含め下部ナビの余白を確保します。ナビの2項目やルートは変えていません。
4. 独立レビューで統合QR印刷の空白ページを発見しました。修正前の架空店舗フォームではA4が4ページでした。印刷時だけ非QR部分のレイアウト領域を除外し、長いフォームからQRだけを印刷する回帰を追加しました。
