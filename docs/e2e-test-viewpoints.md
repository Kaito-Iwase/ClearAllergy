# E2E 観点表の叩き台

## 目的

管理画面と公開画面の主要導線について、人間が E2E テストケースを作るための観点表です。

現時点ではテスト実装ではなく、観点の整理を目的とします。

## 重点確認シナリオ

| 優先 | シナリオ | 期待結果 |
| --- | --- | --- |
| 高 | `UNKNOWN` が1件残った状態で公開ON保存 | API が 400 を返し、公開されない |
| 高 | 他店舗の menuId を管理編集 URL/API で指定 | 404 または認可エラーになり、存在推測を避ける |
| 高 | 原材料名・注意書きが空のメニューを全アレルゲン確定して公開 | 公開でき、公開詳細では原材料未登録または注意書き非表示になる |
| 高 | 公開店舗一覧から店舗詳細、メニュー詳細、戻る | 導線が切れない |
| 中 | スマホ幅でアレルゲン28品目を操作 | ボタンと文言が重ならない |
| 中 | 保存ボタン二度押し | 重複作成・重複更新が起きない |
| 中 | DB 接続失敗時の公開画面 | フォールバック表示になる |
