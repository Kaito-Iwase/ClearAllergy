## 書体・設定色の再精査

同日の追加依頼で、書体の読みづらさと「注目＝黄色、除外＝赤色」を再精査した。変更前の公開Previewでは本文のCSS指定がGeistとその代替だった。日本語用Noto Sans JPは名前だけの指定で読み込まれず、`font-body` / `font-display` も未配信のManropeとNoto Sans JPを指定していた。

さらに写真未設定時の装飾的な緑のグラデーションを廃止した。店舗ヘッダーは白い情報カードにして写真用の高さを予約せず、メニュー画像欄は既存の無彩色背景を使用する。管理側の店舗プレビューも写真なしでは白地・濃い文字、写真ありでは公開画面と同じ半透明の黒い面と白い文字にそろえる。画像の保存・構図・所有権・公開条件は変更しない。

| 候補 | 判断 |
| --- | --- |
| 既存Geist＋日本語OSフォント | 日本語の字形・太さが端末に依存し、本文とクラス指定で優先順が異なるため見送る |
| 日本語OSフォントだけ | 通信量は増えないが端末間の再現性は改善しないため代替として保持 |
| Noto Sans JP | 日本語・英数字と可変ウェイトを同じ書体で表示できるため採用。利用者試験で最良と実証したという意味ではない |

[デジタル庁のタイポグラフィ](https://design.digital.go.jp/dads/foundations/typography/)も参考に、日本語・英数字の本文と見出し・入力欄をNoto Sans JPへ統一した。Nextの既存font機能でビルド時に取得し、アプリと同じoriginから配信する。日本語の分割ファイルを一括preloadせず、必要な文字のファイルを取得する。`swap` と日本語OSフォントの代替により、取得失敗時にも本文を表示する。本文の既定行高は1.7、既存の部品別サイズ・行高・太さは用途ごとに維持する。コード用等幅フォントとアイコンフォントの意味は維持する。

設定は黄色の淡い背景＋濃い黄褐色の文字、赤色の淡い背景＋濃い赤色の文字を使用する。選択欄の枠も濃くし、編集案と適用済みの要約へ同じ色を使う。文字の「注目／除外」と「未適用」の表示を保持し、食品の登録状態とは見出し・文言で区別する。食品状態の分類・色・保証の限界は変更しない。[W3Cの色の使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)と[コントラスト](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)を基準に、色だけに依存しないことと選択欄の文字4.5:1・枠3:1以上をブラウザ回帰で検査する。全面的なWCAG適合の認定ではない。

## 追加修正：掲載結果プレビューのドラッグ（2026-10-07）

ユーザーの画像は店舗カバーの構図編集を指す。`ShopEditClient`、`NewMenuForm`、`MenuEditClient` は同じ `ImageCompositionEditor` を利用するため、共通部品を修正した。実際の変更はこの部品と `menu-image-display.ts`、新規の単体テスト・コンポーネントブラウザ回帰、ランナー入口、関連文書。アップロード・保存・公開側の表示処理は呼び出しを確認し、変更していない。

従来の `startPosition - pointerDelta / 2.5` は、写真のサイズと表示枠を考慮せず常に位置%を減らしていた。写真が枠より小さい軸では写真が逆向きに動き、はみ出す軸では方向が合ってもドラッグ速度が写真・枠・ズームによって変わる。位置を単純に加算へ変えると拡大時の方向が逆になる。

新しい計算は各軸の `移動範囲 = 枠のサイズ - object-fit後の写真サイズ × zoom / 100` を求め、`位置% = 開始位置% + ドラッグpx / 移動範囲 × 100` とする。余白と切り取りで符号が変わり、写真は指／マウスに追従する。従来の整数0〜100%とzoom50〜250%は維持。移動範囲0や画像未読込の軸は動かさず、端では範囲内に制限する。ドラッグ中のtransformアニメーションによる遅れも除去した。

ネイティブタッチの小さな連続ドラッグでは、位置変更後にブラウザのdouble clickが発火して中央へ戻ることも再現した。移動したジェスチャーによる中央リセットを抑止し、意図的なダブルクリックは保持した。元画像比較中は画像上のドラッグ・ホイール・ダブルクリックで編集値を変えず、「元画像を表示中」と案内してカーソルも通常表示にする。構図を保存するには従来どおりフォームの保存が必要。
