## 2. 重要用語の解説（小さいことから全部）

### 2.1 npm って何？

- **npm**（Node Package Manager：Node.jsのパッケージ管理ツール）
- 役割は「ライブラリをインストールして管理すること」

例：

```bat
npm install prisma
```

これは「Prismaというライブラリをプロジェクトに追加する」という意味。

---

### 2.2 npx って何？

- **npx** は「今のプロジェクトに入っているコマンドを実行する」ための道具
- npmでインストールしたツール（Prismaなど）を、パスを意識せず実行できる

例：

```bat
npx prisma -v
```

これは「プロジェクト内のPrismaを使ってバージョン表示」する。

---

### 2.3 Prisma って何？

Prismaは一言でいうと：

- **ORM（Object-Relational Mapping：DBとプログラムを対応づける仕組み）**

もっとわかりやすく言うと：

- 「PostgreSQLのテーブルを、TypeScriptから安全に操作できるようにする道具」

#### Prismaがしてくれること（順番）

1. `schema.prisma` に **テーブル設計**を書く
2. `migrate` で **DBにテーブルを作る/更新する**
3. `@prisma/client` で **TypeScriptからDBを操作する**（SQLを毎回手書きしなくてよい）

---

### 2.4 `schema.prisma` って何？

- Prismaの「DB設計図」
- テーブル（model）や列（フィールド）、型、関連（relation）を書いておくファイル

例（イメージ）：

- `Shop` テーブル（店舗）
- `MenuItem` テーブル（商品）
- `Allergen` テーブル（アレルゲンマスタ）
- `MenuItemAllergen`（商品×アレルゲンの中間テーブル）

---

### 2.5 migrate って何？

- **migration（マイグレーション）**＝「DBの設計変更を履歴として管理し、DBに適用する仕組み」

Prismaでの migrate：

```bat
npx prisma migrate dev --name init
```

この1行がやること：

- `schema.prisma` を読み込む
- 変更点をDBに反映するSQLを作る
- DBに実際に適用する
- 履歴を `prisma/migrations/` に保存する

---

### 2.6 seed って何？

- **seed（シード）**＝「初期データをDBに入れる処理」

今回のseed：

- アレルゲン28品目を `Allergen` テーブルに投入した

メリット：

- 画面側でアレルゲン一覧を表示する時に「必ず28品目が揃っている」状態から始められる
- 手入力ミスや表記揺れを防げる

---

### 2.7 `.env` って何？

- `.env` は「環境変数（Environment Variables）を書くファイル」
- **パスワードや接続URLなど、公開してはいけない情報**を入れる場所

今回の `.env` に入れるものの例：

- `DATABASE_URL`：DB接続文字列
- `NEXTAUTH_SECRET`：NextAuthの秘密鍵

重要：

- `.env` は **GitHubに上げない**（`.gitignore` に入れる）
- 漏れると、DBに勝手に接続されるリスクがある

---

### 2.8 `DATABASE_URL` って何？

- DBに接続するための「住所＋鍵」を1本の文字列で表したもの

例（形）：

```text
postgresql://USER:PASSWORD@HOST/DBNAME?sslmode=require
```

意味（順番に）：

- `postgresql://`：PostgreSQLに繋ぐ
- `USER:PASSWORD@`：ユーザー名とパスワード
- `HOST/DBNAME`：サーバとDB名
- `sslmode=require`：暗号化通信（SSL/TLS）を必須にする指定（Neonでよく必要）

---

### 2.9 Neon って何？

- **クラウドで使えるPostgreSQL**（DBをすぐ用意できるサービス）
- ローカルにDBを入れずに、`DATABASE_URL` を貼るだけで使えるのが強み

今回Neonにした理由：

- DockerやローカルPostgres構築の詰まりを回避して、MVPを早く進めるため

---

### 2.10 tsx って何？（seed実行に使った）

- `tsx` は TypeScriptファイル（`.ts`）をそのまま実行しやすくするツール
- seedをTypeScriptで書いて実行できる

今回：

- `prisma/seed.ts` を `npm run seed` で実行するために使った
